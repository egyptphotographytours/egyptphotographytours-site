Основные аксессуары, включенные или рекомендованные в наших турах

  • Круговой поляризатор:Уменьшает блики на каменных поверхностях и кучах специй; усиливает контраст неба в сценах пустыни

  • Портативный отражатель:Складной отражатель 5-в-1 заполняет тени на рынках и в пустыне, не усложняя вспышку.
  • Мини-штатив:Настольный штатив стабилизирует макросъемку на неровном полу храма или на пустынной поверхности.
  • Набор для чистки линз:Воздуходувка, салфетки из микрофибры, ручка для линз и инструменты для очистки сенсора для ежедневной борьбы с пылью.

Профессиональные инструкции по настройке камеры в наших турах

  • Диафрагма:f/8–f/11 для оптимальной резкости и глубины; остановитесь до f/16 для фокусировки
  • Скорость затвора:Минимум 1/125 с при портативном режиме; используйте штатив для более медленных скоростей на рынках с низкой освещенностью
  • ИСО:Базовое ISO 100 для текстур камня; увеличение до 800-3200 для интерьеров рынка по мере необходимости
  • Режим фокусировки:Ручная фокусировка с выделением фокуса для точного управления текстурами; использовать увеличение фокуса
  • Формат файла:Всегда снимайте в формате RAW для максимального восстановления деталей текстуры и гибкости баланса белого.
