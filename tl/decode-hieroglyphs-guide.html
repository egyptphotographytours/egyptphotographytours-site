Ang Mga Pangunahing Kaalaman ng Hieroglyphs

Ang salitang "hieroglyph" ay nagmula sa Griyego:hieros(sagrado) +glypho(mga inukit). Ngunit tinawag ng mga sinaunang Egyptian ang kanilang pagsulat"mdw nṯr"(medu netcher) – "mga salita ng mga diyos." Inihayag nito ang sagradong katangian ng script na ito na nagtiis ng mahigit 3,500 taon.

Ang Tatlong Uri ng Hieroglyphic Signs

Upang ma-decode ang mga hieroglyph, dapat mong maunawaan na ang mga ito ay hindi lamang "pagsusulat ng larawan." Gumagana ang mga ito sa pamamagitan ng tatlong magkakaibang uri ng mga palatandaan:

Ang Tatlong Uri ng Hieroglyphic Signs
Uri ng SignFunctionMga halimbawaPaggamit
Mga ponogramaKinakatawan ang mga tunog (tulad ng ating alpabeto)𓄤 (nfr = "mabuti"), 𓂋 (r = "bibig")~45% ng mga text
Mga logogramKinakatawan ang buong salita/konsepto𓁹 (ir = "mata"), 𓉐 (pr = "bahay")~35% ng mga text
Mga DeterminativeLinawin ang mga kahulugan ng salita (walang tunog)𓀀 (tao), 𓇋 (diyos)~20% ng mga text

Ang Hieroglyph Alphabet: Ang Iyong Decoding Toolkit

Kritikal na Pag-unawa:Kinakatawan ng mga hieroglyphmga katinig lamang(walang patinig). Ito ang dahilan kung bakit ang mga Egyptologist ay nagdaragdag ng "e" sa pagitan ng mga katinig kapag binibigkas ang mga salita: "nfr" ay nagiging "nefer."

Ang 24 Uniliteral Signs (Single-Consonant Hieroglyphs)

Ito ang iyong pundasyon—ang pinakamalapit na bagay sa isang "alpabeto" sa sinaunang Egyptian. Kabisaduhin ang mga ito, at maaari mong iparinig ang halos anumang salita:

  • 📇 (i):Reed - Madalas na nagsisimula ng mga salita.
  • 𓂋 (r):Bibig - Lubhang karaniwan.
  • 📅 (m):Kuwago - Napakakaraniwan.
  • 𓈖 (n):Water ripple - Nasa lahat ng dako.
  • 𓏏 (t):Tinapay - Pangbabae na pagtatapos.
  • 📄 (ḥ):Twisted flax - Sa maraming pamagat.
  • 📎 (ḥ):Baluktot na mitsa - Mga kontekstong panrelihiyon.
  • 📃 (b):Paa - Mga karaniwang salita.
  • 📊 (p):Stool - Mga pangalan, pamagat.
  • 📆 (f):Horned viper - Mga pandiwa, pangalan.

Para sa mas malalim na pagsisid sa kasaysayan ng mga simbolong ito, tuklasin ang aming gabay saGrand Egyptian Museum, kung saan nakalagay ang marami sa mga orihinal na artifact na nagpapakita ng mga palatandaang ito.

Mastering Reading Direction

Ito ang #1 na hamon para sa mga nagsisimula. Maaaring isulat ang mga hieroglyph mula kaliwa-kanan, kanan-papuntang-kaliwa, o itaas-pababa. Sundin ang mga pahiwatig na ito:

  • Ang mga pigura ng hayop/tao ay nahaharap sa simula:Kung ang mga ibon ay nakaharap sa kanan, basahin ang kanan-pakaliwa.
  • Ang mga palatandaan na walang simetriko ay nagpapahiwatig ng direksyon:Ang bibig na hieroglyph (𓂋) ay bumubukas patungo sa simula ng linya.
  • Binasa ang mga column mula sa itaas hanggang sa ibaba:Pagkatapos ay tukuyin ang kaliwa-kanang direksyon sa loob ng column.

Tip sa Photography Pro

Kapag kumukuha ng larawan ng mga hieroglyph para sa pag-decode sa ibang pagkakataon: Isama angbuong hangganan ng inskripsiyonsa iyong frame, tandaan kung aling paraanmukha ng hayop/tao, at larawan mula sadumiretsopara maiwasan ang distortion. Para sa higit pang mga tip sa pagkuha ng mga detalye ng templo, tingnan ang aminggabay sa litrato ng fresco at nitso.

Grammar at Royal Names

Hindi mo kailangang maging eksperto sa grammar, ngunit ang pag-unawa sa mga pangunahing kaalaman na ito ay lubos na magpapahusay sa iyong pag-decode:

  • 𓏏 (t):Feminine ending (lumalabas pagkatapos ng pambabae nouns).
  • 𓍯𓍯 (w):Pangmaramihang pananda (dalawang sisiw ng pugo = maramihan).
  • 📀 (determinative):Nagsasaad ng tao/lalaki.

Royal Titulary (Mga Pangalan ng Paraon)

Bawat pharaoh ay may limang pangalan. Matutong kilalanin ang mga ito sa mga cartouch (mga hugis-itlog na frame):

  • Pangalan ng Horus:Protektadong falcon (𓅃).
  • Pangalan ng Trono:"Siya ng sedge at bee" (𓆥).
  • Pangalan ng kapanganakan:"Anak ni Ra" + personal na pangalan (madalas makikita sa mga cartouch).

Paulit-ulit mong makikita ang mga pangalang ito sa mga site tulad ngMga Templo ng Karnak at Luxorat angTemplo ng Hatshepsut.

Mga Pamamaraan sa Potograpiya para sa Mga Inskripsiyon

Ang pagkuha ng mga inskripsiyon para sa susunod na pag-aaral ay nangangailangan ng mga partikular na diskarte, lalo na sa madilim na liwanag ng mga libingan o ang malupit na liwanag ng mga panlabas na templo.

  • Gear:Wide-angle (16-35mm) para sa mga dingding, Macro (90-100mm) para sa mga detalye, Polarizing filter para sa pandidilat.
  • Pag-iilaw:Ang pag-iilaw sa gilid ay nagpapakita ng lalim ng pag-ukit. Gumamit ng LED panel kung pinahihintulutan.
  • Mga Setting:Mataas na ISO para sa mga libingan, polarizer para sa mga panlabas na templo.

Mga Madalas Itanong

Posible bang matutong magbasa ng hieroglyph ang mga turista bago bumisita sa Egypt?
Ganap! Sa nakatutok na pag-aaral, matututunan ng mga turista ang pangunahing hieroglyph decoding sa loob ng 2-3 linggo. Kasama sa aming Egypt Photography Tours ang mga pre-trip learning materials at on-site decoding practice kasama ang mga certified Egyptologists. Karamihan sa mga manlalakbay ay maaaring matutong magbasa ng mga simpleng inskripsiyon, pangalan, at karaniwang parirala bago ang kanilang paglalakbay.
Ano ang 3 uri ng hieroglyphic sign?
Gumagamit ang Egyptian hieroglyph ng tatlong uri ng tanda: 1) Phonograms (kumakatawan sa mga tunog, tulad ng isang alpabeto), 2) Logograms (kumakatawan sa buong salita/konsepto), at 3) Determinatives (linawin ang mga kahulugan ng salita nang hindi gumagawa ng tunog).
Paano mo malalaman kung aling direksyon ang magbabasa ng mga hieroglyph?
Maaaring isulat ang mga hieroglyph mula kaliwa-kanan, kanan-papuntang-kaliwa, o itaas-pababa. Ang susi ay tingnan ang direksyon na kinakaharap ng mga hayop at tao. Palagi silang nakaharap sa simula ng linya. Kung ang isang ibon ay nakaharap sa kanan, magbasa ka mula kanan pakaliwa.
Maaari ba akong magsanay sa pag-decode ng mga totoong hieroglyph sa panahon ng Egypt Photography Tours?
Oo! Kasama sa lahat ng aming paglilibot ang mga hands-on na hieroglyph decoding session sa mga archaeological site. Ang amingPribadong Pyramids TourNagtatampok ang Giza tomb inscription decoding, at ang7-araw na Discovery Tourmay kasamang pagsasanay sa pagbabasa sa dingding ng templo sa Luxor at Karnak.
Ano ang pinakakaraniwang pagkakamali ng mga nagsisimula kapag nagbabasa ng mga hieroglyph?
Ang pinakamalaking pagkakamali ay ang maling pagbabasa ng direksyon. Ang mga nagsisimula ay madalas na ipinapalagay na ang lahat ng teksto ay binabasa mula kaliwa-pakanan tulad ng Ingles. Tandaan na palaging suriin ang direksyon na kinakaharap ng mga numero upang matukoy ang simula ng linya.
